## SparkHacks 2024 Website
Website for SparkHacks 2024, opening once hackathon details are finalized to share dates, schedule, and other info for prospective hackers, with applications open through the site as well.

### Requires
- [Git](https://git-scm.com/downloads)
- [nvm](https://github.com/nvm-sh/nvm)
- [Node.js](https://nodejs.org/en/)

### Getting Started
```bash
git clone git@github.com:SparkHacks/spark-web-2024.git
cd spark-web-2024
npm install
```

### Running Locally
```bash
npm run dev
```
